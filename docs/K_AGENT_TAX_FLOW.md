# K-Agent와 세무 문서 검증 흐름

- K-Agent는 데스크톱에서 717px 우측 드로어이며 작은 화면에서만 화면 폭에 맞춘다.
- 메시지 제출 즉시 사용자 말풍선을 표시하고 서버 작업 중에는 AI 점 3개 말풍선을 표시한다. 완료 응답은 새로고침 없이 교체한다.
- 일반 채팅은 이전 상태 조회가 끝난 뒤 다음 조회를 예약한다. 닫힘·화면 변경으로 취소된 요청은 오류 말풍선으로 표시하지 않는다.
- 완료 답변의 타이핑 효과와 출처·주의 문구·다시 생성 버튼은 같은 메시지에서 표시한다. 타이핑 중 닫거나 다른 메시지로 바뀌면 이전 타이머를 정리한다.
- 비로그인 상태의 로그인, History, Delete는 드로어를 닫고 현재 경로를 `returnTo`로 포함한 로그인 화면으로 이동한다.
- 홈의 Check eligibility와 모든 Check my tax rate(홈 바로가기·햄버거 메뉴·푸터)는 현재 페이지를 유지하며 하나의 공통 우측 드로어를 연다. 메뉴에서 실행하면 메뉴를 닫는다. 진입 시 사용자 시작 말풍선, AI 점 3개 대기 말풍선, 안내 답변 순서로 표시한다.
- 이전 독립 TaxPage는 제거했다. 기존 `/tax` 직접 접속·새 탭 열기·로그인 후 복귀는 홈을 배경으로 동일한 세무 드로어를 연다. 닫으면 `/`로 돌아간다.
- 국가 선택과 세율 결과는 `/api/v1/tax/countries`, `/api/v1/tax/eligibility`를 사용한다. 파일 업로드·진행 상태·3개 문서 비교도 기존 인증 API를 그대로 사용하며 진입점별 별도 데이터나 모의 결과를 만들지 않는다.
- 국가 선택은 회원가입과 같은 컴포넌트를 사용한다. 선택 가능한 미국이 맨 위에 오고, 나머지 국가는 이름순으로 정렬해 준비 중·선택 불가로 표시한다.
- 세율 조회도 사용자 선택 말풍선과 AI 대기 말풍선을 먼저 표시한 뒤 결과를 교체한다. 비로그인 안내의 로그인 링크는 채팅 말풍선 안의 검은색 버튼으로 표시하고, 선택 시 드로어를 닫은 뒤 로그인 화면으로 이동한다.
- 로그인 사용자는 거주자증명서, 아포스티유, 제한세율 적용신청서를 순서대로 업로드한다. 각 문서 상태는 자동 갱신되며 세 종류가 끝나면 비교 API를 한 번 호출한다.
- 원문은 프론트에 캐시하지 않으며 브라우저 저장소에도 기록하지 않는다.
