# K-Agent와 세무 문서 검증 흐름

- K-Agent는 데스크톱에서 717px 우측 드로어이며 작은 화면에서만 화면 폭에 맞춘다.
- 메시지 제출 즉시 사용자 말풍선을 표시하고 서버 작업 중에는 AI 점 3개 말풍선을 표시한다. 완료 응답은 새로고침 없이 교체한다.
- 비로그인 상태의 로그인, History, Delete는 드로어를 닫고 현재 경로를 `returnTo`로 포함한 로그인 화면으로 이동한다.
- 홈의 Check eligibility는 별도 전체 화면을 열지 않고 같은 우측 드로어에서 조세조약 조회를 수행한다. 진입 시 사용자 시작 말풍선, AI 점 3개 대기 말풍선, 안내 답변 순서로 표시한다.
- 세율 조회도 사용자 선택 말풍선과 AI 대기 말풍선을 먼저 표시한 뒤 결과를 교체한다. 비로그인 안내의 로그인 링크는 채팅 말풍선 안의 검은색 버튼으로 표시하고, 선택 시 드로어를 닫은 뒤 로그인 화면으로 이동한다.
- 로그인 사용자는 거주자증명서, 아포스티유, 제한세율 적용신청서를 순서대로 업로드한다. 각 문서 상태는 자동 갱신되며 세 종류가 끝나면 비교 API를 한 번 호출한다.
- 원문은 프론트에 캐시하지 않으며 브라우저 저장소에도 기록하지 않는다.
