# K-Agent와 세무 문서 검증 흐름

- K-Agent는 Figma의 1920px 기준 717px 비율인 화면 폭 37.34375%를 따르며 최대 717px, 최소 480px로 동작한다. 1000px 이하 화면에서만 전체 폭을 사용한다. 일반·뉴스·공시·세무·대화 기록이 같은 폭과 반응형 글자·행간·말풍선 패딩·메시지 간격 토큰을 사용한다. 1920px에서는 Figma 원값을 적용하고 좁은 패널에서는 가독성 하한까지 함께 축소한다.
- 계정의 국적·투자자 유형·세무 상태는 `/me` 응답을 사용한다. 페이지 이동과 세무 완료·초기화 시 갱신한다. 완료 상태의 세율 진입 버튼은 `/tax/review`의 검증 문서 보기로 바뀐다.
- `/tax/review`는 업로드 원본 3종과 서버가 생성한 예상 경정청구서 PDF를 자동으로 표시한다. 편집·불러오기·제출 기능은 없고 미확인 금액과 금융사 정보는 작성하지 않는다. 초기화 후에는 이전 완료 자료를 표시하지 않는다.
- PDF는 기본 브라우저 플러그인 대신 PDF.js로 페이지를 직접 표시한다. 서식 입력·문서 스크립트·외부 링크는 활성화하지 않는다.
- 경정청구서에는 원본에서 추출한 생년월일·전화번호·주소도 포함하며, 강조된 칸은 읽기 전용이다. 화면과 PDF의 추가 안내는 EN/KR 선택을 따른다. 과거 서류의 보조 필드 복구 중에는 스켈레톤을 표시하고 완료 후 자동 갱신한다.
- 비교 검증 통과 메시지는 중복 Verified 문구 대신 검증 완료 문서 보기 버튼을 제공한다. 선택 시 세무 드로어를 닫고 `/tax/review`로 이동한다. 미통과 상태에는 이 버튼을 표시하지 않는다.
- 세무·일반 대화의 본문만 세로 스크롤된다. 세무 패널 자체는 스크롤되지 않으며 말풍선·링크·원본 미리보기는 패널 너비 안에서 줄바꿈·축소한다.
- 메시지 제출 즉시 사용자 말풍선을 표시하고 서버 작업 중에는 AI 점 3개 말풍선을 표시한다. 완료 응답은 새로고침 없이 교체한다.
- 공시 Ask·뉴스/공시 드래그 질문은 고유 요청 ID를 만들고, 기존 대화 이력 로딩 후 방 생성 또는 재사용과 실제 전송을 한 번에 수행한다. 입력창에서 다시 전송할 필요가 없다. 동기 전송 잠금과 서버 멱등 키로 effect 재실행·연속 클릭을 차단한다.
- 공시 드래그는 원문·영문 HTML의 같은 `data-section-id` 안에서 선택한 문구를 `selectedSectionId`·`selectedText`로 보낸다. Backend·AI가 현재 원문 또는 완료된 번역 캐시와 대조한다. 후속 일반 질문에 이전 선택을 붙이지 않는다.
- 뉴스 드래그도 `selectedText`를 별도로 전송한다. 공시 섹션 ID를 만들지 않으며 Backend가 현재 기사 원문 또는 같은 원문 해시의 READY 영어 본문으로 검증한다. 선택 주변 문맥은 긴 기사에서도 보존하며 이 검증 때문에 번역을 새로 생성하지 않는다. 원문과 일치하지 않는 선택은 모델 호출 전에 거부한다.
- 언어·기사 변경 또는 채팅 열기 시 선택 말풍선을 닫는다. 서로 다른 공시 섹션·오류·로딩 영역을 가로지른 선택은 질문으로 보내지 않는다.
- 일반 채팅은 이전 상태 조회가 끝난 뒤 다음 조회를 예약한다. 닫힘·화면 변경으로 취소된 요청은 오류 말풍선으로 표시하지 않는다.
- 대화 재진입은 마지막 생성 상태를 메시지보다 먼저 조회해 진행·실패 상태를 복원한다. 진행 중이면 상태 조회를 재개하고 장애로 실패했으면 재시도 버튼을 복원한다. 다른 방으로 이동한 뒤 도착한 이전 조회는 취소하며 연결 복구 시 연결 오류 문구를 제거한다. 이 과정은 AI 재생성이 아니다.
- 완료 답변의 타이핑 효과와 출처 버튼·주의 문구는 같은 메시지에서 표시한다. 정상 답변의 재생성 버튼은 없고, 서버가 `retryable`로 허용한 장애 건에만 재시도 버튼을 표시한다.
- 공시 출처 버튼은 내부 `/disclosures/{접수번호}`로 이동하면서 채팅방을 닫는다. 기존 대화의 DART 주소도 검증된 접수번호로 내부 이동하고, 본문의 주소는 출처 ID로 표시한다. 타이핑 중 닫거나 다른 메시지로 바뀌면 이전 타이머를 정리한다.
- 뉴스·공시 출처 버튼은 EN에서 서버의 `titleEn`, KR에서 `titleKo`를 사용한다. 기존 대화도 동일하며 언어 전환으로 AI를 다시 호출하지 않는다. 검증된 제목이 없으면 원어 제목을 대체 노출하지 않고 이동 동작명만 표시한다.
- 답변 언어는 현재 질문으로 결정한다. 사이트 EN/KR을 채팅 전송에 넣지 않으며, 선택문은 질문과 별도 필드로 보낸다. 언어를 전환해도 기존 질문·답변·주의 문구는 그대로 유지하고 뉴스·공시 출처 버튼의 제목만 선택 언어로 바꾼다. 새 번역·답변 생성은 요청하지 않는다.
- 비로그인 상태의 로그인, History, Delete는 드로어를 닫고 현재 경로를 `returnTo`로 포함한 로그인 화면으로 이동한다.
- 대화 기록의 각 행은 열기와 관리 버튼을 분리한다. 서버 검색·새 대화 생성·버전 검사 이름 변경·확인 후 삭제를 지원하며 임의로 두 번째 행을 선택 상태로 표시하지 않는다.
- 미완료 상태에서 홈의 Check eligibility와 모든 Check my tax rate(홈 바로가기·햄버거 메뉴·푸터)는 현재 페이지를 유지하며 하나의 공통 우측 드로어를 연다. 메뉴에서 실행하면 메뉴를 닫는다. 진입 시 사용자 시작 말풍선, AI 점 3개 대기 말풍선, 안내 답변 순서로 표시한다. 완료 상태에서는 검증 문서 화면으로 이동한다.
- 이전 독립 TaxPage는 제거했다. 기존 `/tax` 직접 접속·새 탭 열기·로그인 후 복귀는 홈을 배경으로 동일한 세무 드로어를 연다. 닫으면 `/`로 돌아간다.
- 국가 선택은 `/api/v1/tax/countries`를 사용한다. 비로그인 세율 안내는 공개 `/tax/eligibility`, 로그인 세무 대화는 `/me/tax-conversation`과 `/eligibility`로 결과를 저장·복원한다. Figma의 세율 결과 → 간단 가이드 → 상세 가이드 → 서류 검증 단계를 `/me/tax-conversation/flow`에 저장해 새로고침 후에도 복원한다. 언어 변경은 기존 대화 결과를 다시 만들지 않는다.
- 두 가이드 선택지의 보조 버튼과 상세 가이드의 마지막 버튼은 모두 서류 검증을 시작한다. 상세 가이드의 원본 다운로드는 배포물에 포함된 최신 별지 제29호의12서식 PDF를 그대로 제공하며 내용을 변형하지 않는다.
- 국가 선택은 회원가입과 같은 컴포넌트를 사용한다. 선택 가능한 미국이 맨 위에 오고, 나머지 국가는 이름순으로 정렬해 준비 중·선택 불가로 표시한다.
- 세율 조회도 사용자 선택 말풍선과 AI 대기 말풍선을 먼저 표시한 뒤 결과를 교체한다. 비로그인 안내의 로그인 링크는 채팅 말풍선 안의 검은색 버튼으로 표시하고, 선택 시 드로어를 닫은 뒤 로그인 화면으로 이동한다.
- 로그인 사용자는 거주자증명서, 아포스티유, 제한세율 적용신청서를 순서대로 업로드한다. 검증 중에는 새 업로드를 잠그고 응답 후 다음 조회를 예약한다. 통과한 경우에만 다음 단계로 진행하며 세 종류가 통과하면 저장된 OCR 필드로 비교한다.
- 사용자 문서는 오른쪽 이미지 말풍선으로 표시하고 `/tax-documents/{id}` 새 탭에서 소유자 인증 후 원본을 연다. 미리보기는 일시적인 메모리 Blob만 사용하며 화면 종료·재시작 시 해제한다. 브라우저 영구 저장소에는 원문을 남기지 않는다.
- AI 검증 말풍선은 하나금융 거래소 앱의 업로드 이미지·주황색 스캔선·진행 표시를 사용한다. 실패 시 `Upload again`은 새 파일 선택창을 열며 실패 원본은 서버에서 파기한다.
- `Start over`는 확인 후 서버의 기존 방·문서·파일을 삭제하고 새 방을 생성한다. 세율 결과와 문서 판정·비교는 새로고침 후에도 복원되고 최근 사용 순서로 목록에 표시한다.
