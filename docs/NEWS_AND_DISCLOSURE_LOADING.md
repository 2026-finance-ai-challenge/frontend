# 뉴스 요약·공시 번역 표시

새 내부 생성 API가 포함된 AI, Backend, Frontend 순서로 연동한다.

## 뉴스

- 홈·뉴스 목록·종목 뉴스·상세는 같은 뉴스 API와 언어별 필드를 사용한다.
- 원문·분류·영어 제목이 준비된 항목만 목록에 공개하며 본문 번역 캐시 유무로 목록을 바꾸지 않는다.
- 기본 카드에 요약이 없으면 호버 안내를 표시한다. 실제 요청 중에는 스켈레톤을 표시한다.
- READY 또는 summaryReady=true이고 현재 locale과 일치하는 완전한 What/Why/Impact만 보여 준다.
- 요약 검증이 끝나면 본문 생성 중에도 갱신한다. 본문 생성 실패 시에도 검증이 완료된 요약은 유지한다.
- 실패 후 새로고침하면 동일 작업의 본문을 재요청한다. 완료된 양언어 요약은 다시 생성하지 않으며 공급자 제한 시간과 서버 중복 방지를 유지한다.
- 터치 화면에서는 카드가 화면 중앙에 400ms 머물 때 요약을 요청한다. 읽는 도중 접혀 화면이 튀지 않도록 열린 요약은 유지한다. 뉴스 목록은 포인터 팝업 대신 카드 내부에 표시한다.
- 카드의 제목·이미지·요약은 문서 흐름으로 배치해 한글 길이와 화면 폭에 따라 높이가 늘어난다.
- EN/KR 전환은 같은 서버 공유 작업에서 해당 언어의 요약을 읽는다. 프론트에서 번역·금액 대체문을 만들지 않는다.

## 공시

- 최초 요청은 POST /api/v1/disclosures/{receipt}/translation 한 번으로 섹션 작업을 등록한다.
- GET 같은 경로에서 문서별 html, total, ready, failed를 조회한다. 미완료 작업이 있으면 2초 간격으로 갱신한다.
- 작업 등록 응답 후 다시 조회한다. 이전 FAILED 캐시를 먼저 읽었더라도 갱신이 멈추지 않는다.
- 공시 요약은 같은 응답의 what/why/impact와 whatKo/whyKo/impactKo 중 현재 언어를 선택한다.
- 영어 화면은 서버가 정제·변환한 원본 HTML을 표시한다. 표 행렬을 프론트에서 새 표로 재구성하지 않는다.
- 병합셀·중첩 표를 유지하며 원문 HTML이 없는 경우 준비 상태를 명시한다. 가짜 본문을 채우지 않는다.
- 준비 중 셀·오류 메시지는 선택할 수 없다. 완료된 원문·번역 영역만 AI 질문을 위한 선택을 허용한다.
- 뉴스·공시 본문의 선택 변경 이벤트를 감지해 모바일 길게 누르기·선택 핸들 조절에도 AI 질문을 연결한다. 안내 문구는 버튼이 아니며 뉴스의 중복 종목번호 태그는 표시하지 않는다.
- 터치·펜 질문 전송은 pointerup에서 처리해 Safari의 click 생략에 대응한다. 뒤따르는 호환 click은 중복 전송하지 않으며 마우스·키보드 입력은 유지한다.
- 한글과 영어 HTML 모두 서버가 원문 섹션 ID를 연결한다. 원문과 섹션 대응을 검증할 수 없는 경우 원문은 보여주되 임의 ID로 드래그 질문을 보내지 않는다.

## 검증 경계

뉴스 본문은 요청 언어와 READY 상태, bodyReady, 비어 있지 않은 문단 배열로 표시 여부를 결정한다. 완료된 본문을 문자·금액 정규식으로 다시 숨기거나 고쳐 쓰지 않는다. 표현 품질 관측은 AI 서버 로그에서 처리하며 제목 사전 번역의 표시 정책은 별개다. 미완료·실패 본문은 완료 결과로 보여주지 않고 먼저 도착한 양언어 요약을 유지한다. Backend와 프론트의 이 정책을 먼저 배포한 뒤 AI의 비차단 관측 정책을 배포한다.

부분 완료·언어 전환·본문 실패·기존 완료 캐시를 단위 테스트한다. 정적 검사와 빌드 통과는 운영 API 연동·브라우저 검증을 대체하지 않는다. 새 Backend API 배포 전에는 새 공시 영어 화면을 운영에 독립 배포하지 않는다.
