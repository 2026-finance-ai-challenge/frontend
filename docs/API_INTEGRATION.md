# KART 화면/API 연결 점검

기준: 2026-09-03 작업 브랜치. 운영 `main` 반영 여부와 코드 연결 여부는 구분한다.

## 연결된 사용자 기능

| 기능 | 실제 연결 |
| --- | --- |
| 회원가입·ID 중복 확인 | `/auth/signup`, `/auth/login-id-availability` |
| 로그인·세션 복원·현재 로그아웃 | `/auth/browser/login`, `/refresh`, `/logout`와 HttpOnly 쿠키. 페이지 재접속·동시 탭·갱신 응답 유실 대응 |
| 프로필·계정 보안 | 로그인/복원 응답의 실제 프로필, `/me/password`, `/auth/logout-all`, `DELETE /me` |
| 내 정보 | 실제 최근 열람 제목·공통 분석 라벨·관심종목·개인화 피드. 예시 인물 사진 대신 공통 기본 프로필 |
| 관심종목·최근 본 항목 | `/me/watchlist`, `/me/recently-viewed`. 종목·뉴스·공시 상세 열람 기록 |
| 알림 | 목록·개별 읽음·전체 읽음 API |
| 채팅 | 방 생성·목록·검색·상세·이름 변경·삭제, 메시지 제출·조회, 생성 상태·중단·장애 재시도 |
| 시장 | 종목 검색·스크리너·상세·지수·환율·외국인 한도·순매수·글로벌 피어·OHLCV 차트·SSE |
| 뉴스 | 목록·검색·상세·온디맨드 EN/KR 요약·영문 본문. 선택 질문은 실제 K-Agent 문맥으로 전달 |
| 공시 | 목록·검색·상세·원본 HTML·번역 상태·전체 번역·AI 요약·색인. 선택 질문은 실제 K-Agent 문맥으로 전달 |
| 세무 | 국가·세율 조회, 인증 파일 업로드·상태 목록·3종 비교 API |

## 아직 연결되지 않은 기능

- 세무 문서 개별 삭제와 장애 재검증 API는 있으나 현재 세무 드로어에 해당 조작 UI가 없다. 문서 상세 API는 별도 호출하지 않고 같은 필드가 포함된 목록 응답을 사용한다.
- 채팅 메시지 API의 `afterSequence` 연속 조회가 연결되지 않아 현재 첫 100개 메시지만 조회한다. 방 검색 목록은 최대 100개다.
- 알림 목록의 다음 커서는 UI에 연결되지 않아 첫 20개만 표시한다.
- 가입의 FSC 고지 확인은 화면에서 필수로 검사하지만 서버 가입 계약에 별도 동의 시각 필드가 없다. 약관·개인정보 동의와 동일한 서버 영속 기록이라고 표시하지 않는다.

## 대체 경로를 사용하는 API

- 본문형 로그인·refresh·logout은 네이티브/과거 검증 클라이언트용이며 현재 브라우저는 쿠키 전용 경로를 사용한다.
- 종목 `/history` 대신 `/chart`, 단독 뉴스 용어 해설·공시 `/questions` 대신 인용을 저장하는 K-Agent 메시지 흐름을 사용한다.
- 개별 공시 섹션 번역 API 대신 전체 문서 번역 요청·조회로 원본 HTML 구조를 유지한다.

API가 존재한다는 사실만으로 UI 연결 완료나 외부 공급자·모델의 실시간 성공을 의미하지 않는다. 모든 Backend 기능이 현재 Frontend에서 사용 가능하다는 판정은 하지 않는다.

## 이번 변경의 실제 검증

- 로컬 Frontend에서 배포 Backend로 새 계정 가입, 로그인, 내 정보 새로고침·연속 재접속, 동시 탭 세션 복원, 로그아웃 후 비로그인 상태를 확인했다.
- 실제 채팅방 생성·이름 변경·검색·삭제와 최근 본 공시 기록, 관심종목 가격·개인화 피드 표시를 확인했다. QA에서 만든 임시 대화만 삭제했다.
- EN/KR 회원 화면과 375px 가입·내 정보 화면을 확인하고 긴 ID의 모바일 레이아웃 붕괴를 수정했다.
- Frontend 테스트 55개와 프로덕션 빌드 통과. Backend 검사는 246개 중 242개 통과·선택 검사 4개 생략이다.
- 메모리만 보관하던 refresh 자격 증명, 회전 시 다른 탭의 access 토큰 조기 무효화, 갱신 응답 유실 후 중복 회전 문제를 각각 수정·회귀 검사했다. 원격 미리보기와 운영 main 배포 완료는 이 로컬 연동 검증과 구분한다.
